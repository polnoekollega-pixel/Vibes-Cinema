# Illuminos — онлайн-кинотеатр

Учебный проект студента группы ИСП-311 по дисциплине
**ПМ.01 «Проектирование и разработка информационных систем»**
(Часть 2 — разработка сайта для компании Illuminos, 72 часа).

## Технологии

- **PHP 7.4+** — серверная часть (авторизация, сессии, CRUD, заказы)
- **MySQL (PhpMyAdmin)** — база данных (таблицы users, contents, categories, orders и др.)
- **HTML5 + CSS3** — вёрстка, анимации, адаптив под мобильные устройства
- **JavaScript (vanilla JS + fetch)** — валидация форм, избранное и оценки без перезагрузки
- **Bootstrap-подход к сеткам заменён собственным CSS** (по дневнику — библиотеки на усмотрение студента; использован собственный лёгкий фреймворк-стиль)

## Возможности

| Роль | Возможности |
|------|-------------|
| **Гость** | Просмотр каталога, фильмов и сериалов, поиск, тарифы |
| **Пользователь** | Регистрация, вход, избранное, оценки, история просмотра |
| **Подписчик** | Всё как у пользователя + активная подписка |
| **Администратор** | CRUD контента, категорий, тарифов, смена статусов заказов |

## Установка и запуск

1. Установите локальный сервер (**Denwer / OpenServer / XAMPP**), запустите Apache и MySQL.
2. Скопируйте папку `illuminos` в корень сервера (для Denwer — в `home/localhost/www/`).
3. Импортируйте базу данных: откройте **PhpMyAdmin** (`http://localhost/phpmyadmin`), вкладка «Импорт», выберите файл `sql/illuminos.sql`, нажмите «Вперёд».
4. Откройте сайт: `http://localhost/illuminos/` (для Denwer — `http://localhost/`).
5. При необходимости поменяйте параметры БД в `includes/config.php`.
